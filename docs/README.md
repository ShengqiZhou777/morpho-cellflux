# Documentation Map

Keep this directory as the public, paper-facing documentation surface.

## Read First

- `SCIENTIFIC_STORY.md` - biological framing and what the method claims.
- `EVAL_PROTOCOL.md` - metric definitions and how to compare methods.
- `REPRODUCING.md` - fresh-clone setup, data layout, and run commands.
- `RESULTS.md` - compact current result snapshot.
- `ARCHITECTURE.md` - repository and pipeline structure.
